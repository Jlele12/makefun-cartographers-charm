A hand-plotted treasure chart of The Isle of Almost-Arrr — an island that does
not exist, drawn entirely in pure-stdlib Python: parchment mottling, an
irregular coastline, mountains, a river, the Sighing Woods, a dashed route
from Port Unpromising to the buried gold, a compass rose, sea serpents and a
lonely ship. Ten legible labels, zero dependencies.

## Run it

```sh
python3 main.py  # writes the 1024x1024 map to /output/entry.png
```
